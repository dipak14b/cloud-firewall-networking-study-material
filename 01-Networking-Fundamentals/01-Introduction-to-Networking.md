# Introduction to Networking

## What is Networking?

Networking is the process of connecting multiple devices to exchange data and share resources.

Examples:

- Laptop accessing internet
- Mobile accessing cloud applications
- Servers communicating within a data center
- Branch offices connected through VPN

## Why Networking is Important?

Modern applications depend on networking for:

- Communication
- Resource Sharing
- Internet Access
- Cloud Connectivity
- Security
- Business Continuity

## Components of a Network

### End Devices

- Computers
- Laptops
- Servers
- Mobile Phones

### Intermediary Devices

- Switches
- Routers
- Firewalls
- Load Balancers

### Transmission Media

- Copper Cable
- Fiber Optic Cable
- Wireless

## Types of Networks

### LAN

Local Area Network

Examples:
- Office Network
- Home Network

### WAN

Wide Area Network

Examples:
- MPLS
- SD-WAN
- AWS Direct Connect

### MAN

Metropolitan Area Network

### PAN

Personal Area Network

Example:
- Bluetooth

## Real-World Example

When a user opens https://www.google.com:

1. DNS resolves the domain name.
2. Traffic leaves the client device.
3. Router forwards packets.
4. ISP forwards traffic.
5. Google receives the request.
6. Response is sent back to the client.

## Summary

Networking enables communication between systems and forms the foundation of cloud infrastructure and enterprise networking.
