# Networking Fundamentals

## Overview

Networking is the foundation of all modern IT infrastructure. Understanding networking concepts is essential before working with Cisco, AWS, Azure, GCP, FortiGate, Palo Alto, or hybrid cloud environments.

This module covers:

- Networking Basics
- OSI Model
- TCP/IP Model
- IPv4 Addressing
- Subnetting
- DNS
- DHCP
- NAT
- TCP vs UDP
- Network Devices

## Learning Objectives

After completing this module, you should be able to:

- Explain network communication
- Understand packet flow
- Perform subnet calculations
- Troubleshoot DNS issues
- Understand routing concepts
- Differentiate TCP and UDP traffic
